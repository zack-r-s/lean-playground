# lean-playground

A personal sandbox for experimenting with [Lean 4](https://lean-lang.org/): small programs, proofs, and tactic experiments.
Each example is self-contained in its own folder under `LeanPlayground/` (e.g. `Logic/`, `Lists/`, `BinaryTree/`) and is imported from `LeanPlayground.lean`.
Build everything with `lake build`, and run the demo with `lake exe playground`.
